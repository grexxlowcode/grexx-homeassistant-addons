# Energyboxx Gateway Add-on

Home Assistant add-on that sends your energy sensors (P1 meter, solar, battery, EV charger, gas) to the Energyboxx platform, so your home counts in your energy community.

## Usage

1. Open your home's "Connect Home Assistant" page on the Energyboxx platform and copy the connection code.
2. Install this add-on, paste the code in its Configuration tab and start it.
3. Back on the platform, check which sensors arrived and confirm what each one measures.
