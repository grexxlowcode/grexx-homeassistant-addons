# Energyboxx Remote Access Add-on

Lets Energyboxx support open your Home Assistant when you ask for help, without exposing Home Assistant to the internet and without opening ports on your router.

## Usage

1. Open your home's "Remote access" page on the Energyboxx platform and copy the access code.
2. Install this add-on, paste the code in its Configuration tab and start it.
3. Stop the add-on when support is done. Remote access ends immediately.

Support still needs a Home Assistant login. See [DOCS.md](DOCS.md) for details.
